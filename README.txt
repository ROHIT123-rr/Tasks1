TASK 1 — BASICS OF WEB DEVELOPMENT

Files:
- index.html  : webpage structure and content (HTML)
- style.css   : colors, typography, spacing, cards and responsive layout (CSS)
- script.js   : click event and alert message (JavaScript)

HOW TO RUN
1. Extract the ZIP file.
2. Open the task1_web_development folder.
3. Double-click index.html, or open it in Visual Studio Code and use Live Server.
4. Scroll to “Try the JavaScript button” and click “Click me!” to test the interaction.

TASK CHECKLIST
[✓] HTML headings, paragraphs, links and semantic page sections
[✓] CSS colors, fonts, spacing, layout, hover effects and mobile responsiveness
[✓] JavaScript button click event that displays a message and an alert
